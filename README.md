#### 🏥 [NHS GP Appointments ETL Pipeline](https://github.com/deepanshuantil/lsa-oct-2026)

End-to-end pipeline on real NHS England GP appointment data (**~1.55M rows**).

- ✅ **Quality:** **46 tests** + **9/9 checks** pass
- 📦 159 MB CSV → **5.6 MB Parquet**

#### 🩻 [Chest X-ray Pneumonia Classification](https://github.com/deepanshuantil/chest-xray-pneumonia-classification)

Classifies paediatric chest X-rays as **Normal**, **Bacterial** or **Viral** pneumonia.

- 🧪 Compared 4 transfer-learning models: **ViT-B/16 87.7%**, EfficientNet-B5 87.1%, Xception 87.1%, ResNet-50 85.1% (v1)
- 🎯 F1 **0.97** on Normal cases; main errors are bacterial vs viral
- 🔧 **v2:** found and fixed a data-leakage flaw with a patient-level split
